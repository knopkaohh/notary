# Нотариус Давыдова Евгения Петровна

Современный сайт нотариальной конторы города Москвы. Информация перенесена с действующего ресурса [davydova-notarius.ru](https://davydova-notarius.ru/): услуги, адрес в БЦ «Монарх», график, телефон и юридические документы.

## Что внутри

- Премиальный дизайн с золотом и тёплым бумажным фоном
- Загрузочный экран с монограммой
- Анимации появления блоков
- Онлайн-запись на приём
- Карта проезда и мобильная панель звонка

## Запуск

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Откройте [http://localhost:43123](http://localhost:43123) — dev-сервер по умолчанию слушает этот порт в `package.json`.

Сборка для продакшена:

```bash
npm run build
npm start
```

## Заявки с формы

Форма «Записаться» отправляет данные на `/api/appointment`. В этой версии заявка проверяется на сервере и логируется. Чтобы письма уходили на `6909600@bk.ru`, подключите почтовый сервис (Resend, SMTP) в обработчик API.
